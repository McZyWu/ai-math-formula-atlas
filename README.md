# AI 数学公式图谱

一个面向机器学习、大模型与强化学习的中文交互式数学公式库。它不只罗列结论：每条公式都包含变量解释、推导或构造过程、完整数值算例、资料来源和可交互运算演示。

## 当前覆盖

- 148 个独立公式条目，7 条知识主干
- 高等数学与优化：极限、微分、多元微分、泰勒展开、约束优化、一阶/二阶/自适应优化
- 线性代数：矩阵运算、范数、线性系统、特征分解、正定性、SVD、最小二乘投影
- 概率论与统计：PMF/PDF、联合/边缘/条件概率、贝叶斯、期望、方差、协方差、高斯、混合分布、MLE/MAP、信息论
- ESL 经典机器学习：回归、正则化、判别分析、样条、核方法、模型选择、Bootstrap、EM/MCMC、树与 Boosting、SVM、近邻、聚类、降维、随机森林、集成、图模型与高维推断
- 神经网络与深度学习：激活、损失、反向传播、归一化、初始化、卷积、RNN/LSTM、残差网络
- 大模型、MoE、训练与推理：Attention、MHA、位置编码、RoPE、因果目标、PPL、AdamW、混合精度、SFT、DPO、MoE 路由/容量/均衡、KV Cache、采样、量化、推测解码
- 强化学习与马尔可夫过程：马尔可夫链、平稳分布、MDP、Bellman 方程、策略梯度、TD、SARSA、Q-learning、Actor–Critic、GAE、PPO

## 资料覆盖

- 用户提供的 `MPHY0041_2021_03_math_foundations.pptx` 已逐页检查；第 4–15 页全部数学主题均映射到带“PPT 必含”标签的公式条目。
- [ESL-CN](https://github.com/McZyWu/ESL-CN) 的 18 章目录已建立覆盖映射；每个经典统计学习条目链接到对应章节。
- 现代深度学习、LLM、MoE 与强化学习部分采用通行定义和标准推导补充。

> 定义不能循环证明。因此定义类条目标注为“定义/构造”，展示从动机、约束到最终形式的构造链；定理和算法条目展示实际推导链。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm run build
npm test
```

## 内容结构

- `lib/formulas.ts`：强类型公式目录；每条记录必须有变量、至少两步推导、算例和来源。
- `components/MathFormula.tsx`：KaTeX 公式渲染。
- `components/VisualLab.tsx`：曲线、矩阵、分布、回归、注意力、MoE、优化和马尔可夫交互实验。
- `app/page.tsx`：搜索、筛选、知识目录和公式详情工作台。
- `tests/rendered-html.test.mjs`：成品页面与公式完整性测试。
